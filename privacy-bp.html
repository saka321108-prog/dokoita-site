Blood Pressure Notes Privacy Policy

Last updated: October 22, 2026

This Privacy Policy describes how the developer ("we", "us", or "our") handles user information in the mobile application "Blood Pressure Notes" (the "App"), which is available for Android and iPhone.

1. Information We Handle

The App handles the following information only on the user's device.

Information entered by the user

  • Blood pressure readings (systolic, diastolic, pulse)
  • Measurement tags (arm used, body position), blood oxygen level, height, weight, waist measurement
  • Free-text notes
  • Medication log (whether medication was taken, and how many times per day)
  • Optional profile information (nickname, date of birth, gender) under the "About me" feature

Information handled automatically

  • Device storage (for saving app data and for backup/export files)

The App does not use a camera, microphone, location, or voice input, and does not use any advertising or analytics service. The App does not send any data over the internet and does not connect to any server of ours.

Some screens contain links (for example, to the developer's website or to an app store page). These links open in your device's browser or app store only when you tap them. No data from the App is sent when you do so.

2. Where Information Is Stored

All data entered by the user is stored only on the user's device, in the App's local database.

No data is ever transmitted to or stored on our servers, or on any third-party server.

When data is saved to storage via the PDF/CSV export or ZIP backup/restore function, the destination is limited to the user's device or a location the user chooses (such as the Downloads folder on Android, the Files app on iPhone, or an app the user selects to share the file with).

3. Device Permissions Used

On some older versions of Android, the App uses the storage permission to save and read the App's backup files (PDF, CSV, ZIP) that the user explicitly creates or imports. On newer versions of Android and on iPhone, the App does not request any permission for these features.

The App does not request camera, microphone, location, or internet-related permissions.

4. Data Export and Sharing

The App provides features that allow users to export or share their data externally:

  • CSV / PDF export
  • ZIP export and import (full backup and restore, including settings)
  • Sharing exported files via messaging apps, email, or other apps installed on the user's device

These actions are performed only when the user explicitly initiates them. How information is handled once shared to another app is the responsibility of the user and that app's own provider.

5. Disclosure to Third Parties

We do not disclose user information to any third party. The App does not share data with any external service, advertising network, or analytics provider, because the App does not send data over the internet.

6. Children's Privacy

The App is not directed to any specific age group. We do not knowingly collect personal information from children under the age of 13. In any case, all information the App handles stays on the user's own device and is never transmitted anywhere.

7. Security

Because the App stores data locally on the device, the security of the device itself (screen lock, keeping the OS up to date, etc.) is most important. Users are responsible for appropriate device management. We recommend keeping a copy of your ZIP backup in a safe place, since data stored only on the device can be lost if the device is lost, damaged, or reset. On iPhone, deleting the App also deletes its data.

8. Changes to This Policy

This policy may be updated as needed. Any changes will be published on this page.
