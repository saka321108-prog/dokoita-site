🔑 How to get an API key

🔑 API 키 받는 방법

🔑 获取API密钥的方法

🔑 取得API金鑰的方法

AIでレシートを読み取りたい人だけが行います。下の動く画面を見ながら、6つの手順を進めてください。

Only people who want to read receipts with AI need to do this. Follow the 6 steps while watching the moving screens below.

AI로 영수증을 읽고 싶은 분만 하시면 됩니다. 아래의 움직이는 화면을 보면서 6단계를 진행해 주세요.

只有想用AI读取收据的人才需要操作。请一边看下面的动态画面，一边完成6个步骤。

只有想用AI讀取收據的人才需要操作。請一邊看下面的動態畫面，一邊完成6個步驟。

費用についてAIの利用料は、ご自分で買った「クレジット」から、使った分だけ引かれます。DokoOitaの開発者に支払うものではありません。

About the costAI usage is deducted, only for what you use, from the "credits" you bought yourself. It is not paid to the developer of DokoOita.

비용에 대해AI 이용료는 직접 구입한 "크레딧"에서 사용한 만큼만 차감됩니다. DokoOita 개발자에게 지불하는 것이 아닙니다.

关于费用AI的使用费，会从您自己购买的“额度”中按使用量扣除，并不是支付给DokoOita的开发者。

關於費用AI的使用費，會從您自己購買的「額度」中依使用量扣除，並不是支付給DokoOita的開發者。

キーの扱いキーは、パスワードと同じ大切なものです。ほかの人に見せないでください。他の人に知られたときは、「API keys」の画面でそのキーを削除して、新しく作ります。

Handling the keyThe key is as important as a password. Do not show it to other people. If someone else learns it, delete that key on the "API keys" screen and create a new one.

키 관리키는 비밀번호만큼 소중합니다. 다른 사람에게 보여주지 마세요. 다른 사람이 알게 되었다면 "API keys" 화면에서 그 키를 삭제하고 새로 만드세요.

密钥的保管密钥和密码一样重要，请不要给别人看。如果被别人知道了，请在“API keys”画面删除该密钥，再重新创建。

金鑰的保管金鑰和密碼一樣重要，請不要給別人看。如果被別人知道了，請在「API keys」畫面刪除該金鑰，再重新建立。

うまくいかないとき「APIキーが正しくないようです」と出たら、コピーした文字を、最初から最後まで貼り付けたか確認します。「残高が足りない」と出たら、Billingでクレジットを買い足します。

If it does not workIf you see a message that the API key seems incorrect, check that you pasted the copied text from the very first to the very last character. If you see a message that the balance is too low, buy more credits under Billing.

잘 안 될 때"API 키가 올바르지 않은 것 같습니다"라고 나오면, 복사한 문자를 처음부터 끝까지 붙여넣었는지 확인합니다. "잔액이 부족합니다"라고 나오면 Billing에서 크레딧을 추가로 구입합니다.

不顺利时如果提示API密钥似乎不正确，请确认是否从头到尾完整粘贴了复制的文字。如果提示余额不足，请到Billing再购买额度。

不順利時如果提示API金鑰似乎不正確，請確認是否從頭到尾完整貼上了複製的文字。如果提示餘額不足，請到Billing再購買額度。
